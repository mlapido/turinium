# Contributing to Turinium

## Code Formatting
Turinium follows **PEP 8** formatting. To ensure consistency, we recommend:

- **Auto-formatting with Black:**  
  Run: `black .`
- **Linting with Flake8:**  
  Run: `flake8 turinium/`
- **Static type checking with MyPy:**  
  Run: `mypy turinium/`
